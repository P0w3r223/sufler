# Dokumentacja Sufler

Układ wg [Diátaxis](https://diataxis.fr/) — cztery typy dokumentów dla czterech
różnych potrzeb czytelnika:

| Katalog | Dla kogo / kiedy |
|---------|------------------|
| [`tutorial/`](tutorial/) | Uczysz się — „uruchom Sufler pierwszy raz". |
| [`how-to/`](how-to/) | Masz konkretne zadanie — „dodaj narzędzie", „dodaj drzwi". |
| [`reference/`](reference/) | Szukasz faktu — katalog narzędzi, klucze konfiguracji, schemat notatki. |
| [`explanation/`](explanation/) | Chcesz zrozumieć „dlaczego" — architektura. |

Dodatkowo:

- [`roadmap.md`](roadmap.md) — fazy projektu i **„jesteśmy tu"**.
- [`roadmap-v1-gap-analysis.md`](roadmap-v1-gap-analysis.md) — luki wobec Roadmapy V1 i co je zamknęło.
- [`adr/`](adr/) — Architecture Decision Records (decyzje i ich uzasadnienie).
- [`research/`](research/) — udokumentowane wyniki researchu (po angielsku).
- [`reference/gaps.md`](reference/gaps.md) — audyt gotowości wdrożeniowej. **Migawka z 2026-07-30**,

  decyzji i klasy ryzyka; stan bieżący bierz z kodu.
